# Modoss — Free in-browser makers for 3D printing & crafts

[![Website](https://img.shields.io/badge/website-codex.ski-123f38)](https://codex.ski)
[![Pricing](https://img.shields.io/badge/pricing-freemium-f59e0b)](https://codex.ski/pricing)

**Modoss** (Chinese: 模老板) is a growing collection of small, focused design tools that run in your browser and export files you can actually make — **STL / 3MF** for 3D printing, **SVG / DXF** for laser cutting, and PNG. Most tools compute locally on your device, there is nothing to install, and generation + preview are free.

👉 **Try it: https://codex.ski**

## How it works
1. Open a tool and upload an image or enter your text.
2. Tune the parameters; preview in the browser for free.
3. Export a print/cut-ready file and make it.

## Pricing
Generation and preview are free. A premium printable export is free for members; non-members use a single-use punch-card credit, and **new users get their first export free**. See https://codex.ski/pricing.

## Notes
- Most tools run fully client-side; a few heavier ones (e.g. Portrait Mesh) use a small server pipeline.
- Outputs are decorative/novelty items, not real vehicle plates, and use no third-party IP (brick models are generic "bricks", not LEGO).
